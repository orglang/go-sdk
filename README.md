# OrgLang Go SDK

Go-библиотека с типами и спецификациями OrgLang.

## Структура

- `adt/` — публичные типы и алгебраические структуры данных.
- `pool/` — публичные спецификации и модели pool-компонентов.
- `proc/` — публичные спецификации и модели process-компонентов.
- `prog/` — публичный API для описания и разбора программ OrgLang.
- `lib/` — общие технические интеграции, не являющиеся частью предметного API.

Пакеты `adt/`, `pool/`, `proc/` и `prog/` являются частью Go API модуля. Внутренние детали реализации, не предназначенные для импорта пользователями SDK, размещаются в `internal/`. Типы, используемые в экспортируемых сигнатурах, должны находиться в доступном потребителю пакете.

## Разработка

- `task sources` — форматирование, vet и статические проверки.
- `task tests` — запуск тестов всех пакетов.
