# OrgLang Go SDK

Go-библиотека с типами и спецификациями OrgLang.

## Структура

- `adt/` — публичные типы и алгебраические структуры данных.
- `pool/` — публичные спецификации и модели pool-компонентов.
- `proc/` — публичные спецификации и модели process-компонентов.
- `prog/` — публичный API для описания и разбора программ OrgLang.
- `lib/` — общие технические интеграции, не являющиеся частью предметного API.

## Публичный API и pkg/

Для новых публичных переиспользуемых пакетов рекомендуем использовать `pkg/<package>/`, если это делает границу API явной и удобной для потребителей. `internal/` предназначен для деталей реализации, которые не должны импортироваться извне модуля.

Существующие `adt/`, `pool/`, `proc/` и `prog/` уже являются частью публичного API с опубликованными import path. Оставляем их на текущих путях, чтобы это изменение структуры не стало необъявленным breaking change. Их перенос в `pkg/` возможен только как отдельная версионируемая миграция с обновлением всех потребителей. Типы, используемые в экспортируемых сигнатурах, должны находиться в доступном потребителю пакете.

## Разработка

- `task sources` — форматирование, vet и статические проверки.
- `task tests` — запуск тестов всех пакетов.
